The relation must have a primary key. Repeating groups are not permitted.
Using row order to convey information is not permitted. Make the ordering factor to be a field in the relation. I.e if we are ordering by height make a height field.
Mixing data types is not permitted. I.e a height field cannot have the height as an integer and a tuple has it's height as "somewhere between x and x+2 cm".
