__Unified Modelling Language or UML__ is a standardised way to represent the design of a system.

| Sign | Visibility |
| ---- | ---------- |
| +    | public     |
| -    | private    |
| #    | protected  |

| Attribute                         |
| --------------------------------- |
| modifier attributeName : DataType |

| method                                         |
| ---------------------------------------------- |
| modifier methodName(ArgType args) : ReturnType |

## Examples
| Access | Attribute             |
| ------ | --------------------- |
| +      | name : String         |
| -      | admissionNumber : int |
| #      | height :byte          |

| Access | Attribute           |
| ------ | ------------------- |
| +      | showName(): String  |
| -      | showAdNo() : int    |
| #      | showHeight() : byte |
