The TCP/IP or Internet model is the actual model which is used for communication in the internet and that is why it is also called the internet model. It consists of 4 layers.

| Layer | Name           | Examples    |
| ----- | -------------- | ----------- |
| 4     | Application    | HTTP        |
| 3     | Transport      | TCP/UDP     |
| 2     | Internet       | Ipv4/Ipv6   |
| 1     | Network Access | mac Address |
