## Key Terms

__Relation__ is a table with rows and columns.
__Tuple__ is a row of a relation.
__Attribute__ is a named column of relation.
__Domain__ the set of allowable values for one or more attributes.
__Degree__ is the number of attributes.
__Cardinality__ is the number of tuples in a relation.
__Relational Database__ is a set of normalised relations with distinct relation names.
__Relational Schema__ is a named relation defined by a set of attributes and domain pair names.
__Relational Database__ is a set of relational schema, each with a distinct name.

## Cartesian Product of Relation

This is a set that the first element is from the first set while the second element is second set.

## Properties of Database Relations

1. Relation names is distinct from other relation names in the relational schema.
2. Each cell of a tuple contains exactly one atomic (single) value.
3. Each attribute has a single name.
4. The values of the attributes are all from a single domain.
5. Each tuple is distinct.
6. The order of attributes in a relation has no significance.
7. The order of tuple in a relation has no significance theoretically.
