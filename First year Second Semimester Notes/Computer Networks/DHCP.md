Dhcp server uses udp port 67.
Dhcp client uses udp port 68.
dhcp discover - broadcast message asking if their is a dhcp server in the network
dhcp offer - unicast/broadcast message offering a ip address to the client
dhcp request - a broadcast message that tells the dhcp server they have accepted the address that they have been given.
dhcp ack - tells the dhcp client that they have acknowledged that they are going to use that dhcp offer given.
DORA - discover offer request acknowledge
