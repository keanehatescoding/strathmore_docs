The determinant of a matrix is the scaling factor that the matrix stretches squishes and/or rotates out any area in the span of the vector.
If $A$ is a matrix that maps a vector $\vec x$ to a new vector $\vec v$. Then the following can occur depending on the determinant of matrix A.
1. If the determinant of matrix $A$ is zero then the matrix transformation $\matrix A\vec x$ maps vector $\vec x$ to either a point,a line or a lower dimension.
2. If the determinant of matrix $A$ is greater then zero then it maps vector $\vec x$ to another vector in the same1.

If $A$ is an square matrix then:
1. if $B$ is obtained from $A$ multiplying a row or column by a scalar k, then $|B|=k|A|$ , if twice then $|B| = k^2|A|$ and so on.
2. if $B$ is obtained from A swapping two rows or columns, then $|B|=-|A|$.
3. if $|B|$ is obtained from $A$ by adding a multiple of one row(or column) to another then $|det A|=|det B|$

## Inverse of a matrix

Inverse of a matrix is a unique matrix such that when you multiply a vector by a matrix then the inverse of the matrix it gives you a result equivalent the original vector.
$$ \matrix A^{-1}A\vec {x}=\vec x$$
or
$$\matrix A^{-1}A\vec {x}=\mathbb{I}.\vec{x}$$
where $mathbb{I}$ is the identity matrix.
