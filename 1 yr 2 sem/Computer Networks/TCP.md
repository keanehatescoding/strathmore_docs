<abbr title="Tranmission Control Protocol">TCP</abbr> is a stateful communication between at-least two hosts. The two host first perform a three way handshake before beginning communication.
A TCP three way handshake consists of:
1. __SYN__ message
2. __SYN-ACK__ message
3. __ACK__ message

The TCP flags consists of:
1. TCP-<abbr title="Synchronisation">SYN</abbr>
2. TCP-<abbr title="Acknowledgment">ACK</abbr>
3. TCP-<abbr title="Finish">FIN</abbr>
4. TCP-<abbr title="Reset">RST</abbr>
5. TCP-PUSH
