Transmission Control Protocol/Internet Protocol is the actual model of how devices communicate with each other in the internet.
It is known as TCP/IP because those are the 2 foundational protocols in the suite.
It was developed by by the US DoD through DARPA
It consists of the following layers:

| Number | Layer       | PDU     |
| ------ | ----------- | ------- |
| 4      | Application | Data    |
| 3      | Transport   | Segment |
| 2      | Internet    | Packet  |
| 1      | Link        |         |
