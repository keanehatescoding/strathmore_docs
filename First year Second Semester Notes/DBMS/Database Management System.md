This is a collection of interrelated data and a set of programs to access, manipulate those data.

## Applications

1. Sales industries - supermarkets, online stores, retail stores
2. Finance - stocks
3. Banking
4. Education institutions- Universities, schools
5. Manufacturing sector
6. Reservation industries - aeroplane tickets, railway tickets
7. Telecommunications details
8. Insurance companies

A __table__ is a data structure that arranges data in rows and columns.

## Functions

1. Data Storage, Retrieval and Update
2. Transaction Support
3. Concurrency Control Services
4. Recovery Services
5. Authorization Services
6. Integrity Services
7. Utility Services
8. Support for data communication
9. Services to promote data independence
