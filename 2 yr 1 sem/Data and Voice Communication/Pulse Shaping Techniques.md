There are 3 pulse shaping techniques namely:
1. Unipolar
2. Polar
3. Bipolar

## Polar

| Bits | Level |
| ---- | ----- |
| 1    | +a    |
| 0    | -a    |


## Bipolar
There are 3 amplitudes in bipolar so it is referred to as __psuedo ternary__ code. Bipolar pulse shaping technique is also known as <abbr tile="Alternate Marked Inversion"><b>AMI</b></b> code.

| Bits | Level |
| ---- | ----- |
| 1    | +a,-a |
| 0    | 0     |
