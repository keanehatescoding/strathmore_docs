This is a reference model used to describe how nodes communicate.
A reference model that describes the functions that must be completed at a particular layer, but not specify how exactly a function should be completed.
It is called the Open Systems Interconnection model and was developed by ISO(International Organization for Standards).
It has 7 layers namely

| Layer | Name         |
| ----- | ------------ |
| 7     | Application  |
| 6     | Presentation |
| 5     | Session      |
| 4     | Transport    |
| 3     | Network      |
| 2     | Data Link    |
| 1     | Physical     |
