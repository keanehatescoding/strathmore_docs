## Primitives
__These are data types that lack methods and are the fundamental data types for the java language.__ I.e a int is just a 32 bit signed numeric value that can only be performed numeric operations and be returned as the return type. Other primitive data types are:
1. Boolean 
2. Char
3. Byte
4. Short
5. Int
6. Long
7. Float
8. Double

## Non Primitive types
__These are an extension to the primitive types and offer much more as compared to the primitive types.__ I.e Strings are non primitive data types and offer much more i.e length() method which gives as the length of string. Some of the non primitive data types are:
1. Generic arrays i.e int[], double[] and float[] arrays.
2. Strings which are arrays of chars -> char[]
