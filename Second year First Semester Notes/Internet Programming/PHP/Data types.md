php is a loosely/dynamically typed language
```php
// Strings
$variable = "String"
// Integer
$number = 1
// float
$float = 3.14
// boolean
$boolean = true
// null type
$x = null
// Arrays
$newArray = array(1,2,3,4)
$letters = array('a','b','c')
```
The __var_dump()__ function is used to get the type of a variable.

## Typecasting
to typecast a value type as follows:
```php
$number = 5
$number = (string) $number
```
