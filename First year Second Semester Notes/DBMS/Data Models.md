These are conceptual tools that describe the underlying structure of the database. 
They include a set of basic operations for specifying retrievals or updates to the database.
They also include concepts to specify the behaviour of a database application.

## Categories of Data Models

1. Relational model
2. Entity-Relationship model
3. Object-based data model
4. Semi-structured data model
5. Network data model
6. Hierarchical data model
__NB__:There are many other data model but we will be focusing on the first 4.

## 1. Relational model

Consists of tables.
Tables represent both __data__ and __relationships__.
It is called a relational model because in Relational Database Management Systems we refer to tables as __relations__ because everything is of relation, i.e all the data is stored in relations and the relationships in relations only.
It is also referred to as __record-based model.__

## 2. Entity-Relationship Model

It consists of a collection of basic objects called __entities__ and its __relationship(s)__.
An entity is a real-world object that is distinguishable from other objects.
This model is widely used in database design.

## 3. Object-Based Model

It is used when using a OOP i.e Java, C++, C# as a back-end language for a database.
Object-Based Model = E-R model + Object Oriented features
Object-Relational Data Model = Relational Model + Object-Based Model

## 4. Semi-structured Model
It deals with specification of data.
Individual data items may be of the same type but have different sets of attributes.
This model contrasts with other data models.
Supported by the xml language.
__NB__: Xml is like html but the difference is html onlyhas predefined tags while xml you can define your owntags.
