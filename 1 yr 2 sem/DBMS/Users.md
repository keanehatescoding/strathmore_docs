There are 4 types of users in a database management system:

1. Naive users - unsophisticated users who interact with the system by interacting one or more application programs that were previously written.
2. Application programmers.
3. Sophisticated users
4. Specialized users

## 1. Naive Users

They are unsophisticated users who have little to no knowledge of how the actual database works but they frequently access the system through invoking/using graphical application programs.
Examples of naive users of a database management system are:

 1. Clerks
 2. Customers

## 2. Application programmers

These are the users that know how to write application programs that interact with the database and provide graphical interfaces to the naive users.

## 3. Sophisticated users

They know all the corners of the system and know how to interact with it.
They know how to use the database query languages.
They also know how to use analysis software

## 4. Specialized users

They use specialized database application i.e CAD software to interact with the database.

## Database Administrators

1. Granting authorization for data access.
2. Periodically backing up the database.
3. Define the schema, storage structure and access method.
4. Permits or denies modification to the database schema, physical-organization.
5. Check on disk management space.
6. Ensure database performance is optimum.
