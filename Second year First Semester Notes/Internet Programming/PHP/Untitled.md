The difference between the __echo__ keyword and the __print__ keyword is the echo keyword has no return value while the print keyword has a return value of 1.. Echo is also marginally faster than the print keyword
The difference between using strings that are surrounded by single quotes and double is when using single quotes you must use the following syntax
```php
echo 'Hello from ' . $name '. how do you do?'
```
while when using double quotes you can insert variables into the strings like format strings i.e
```php
echo "Hello from the $name. How do you do"
```
