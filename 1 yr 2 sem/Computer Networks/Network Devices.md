1. Client - this is a pc/phone or any other device that is requesting a service from another computer.
2. __Server__ - this is a device that is sending services to a client/ clients.
3. __Switch__ - this is a device that is used to connect multiple computers together using LAN cables in a LAN
4. __Router__ - this is used to connect two or more subnets or networks together.
5. __Firewall__ - this is used to monitor and control traffic coming into a network or a host.
6. __Next-Generation Firewalls__ are special firewalls that have both traditional firewall capabilities as well as advanced filtering capabilities.
