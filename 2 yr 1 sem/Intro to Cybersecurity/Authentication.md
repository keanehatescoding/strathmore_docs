## Authentication Steps
__Identification__ -Users supply their name to the system they are trying to access (user id or login name)
__Challenge__ the authenticating system responds by challenging the user to prove their reported name; usually a request for a password, but can
be something more involved.
__Response__ the user offers proof to the system that validates the reported identity. This usually involves just typing in a password.
__Validation__ Involves a system checking the validation proof offered to make sure it is as expected.
__Notification__ Once the proof has been checked, the system then provides notification of the authentication decision back to the user. Incorrect
attempts might require notification as well. If enough bad attempts are made, the notification might be that the process has failed
and a time-out has been imposed.
