# Networks

What is a network? A network is a collection of computers connected via a transmission media and protocols.

## Type of Networks

1. Client-server networks - where computer(s) request resources i.e printing services, email services etc to a computer from a usually more powerful computer called a server i.e a web server, proxy etc.
In the past these clients were much less powerful and clients were basically terminals that used to just process instructions and data that the powerful servers would use to process data and transmit the processed data back to the clients.
2. Peer to peer networks - a network were computers are mostly connected to each other for just sharing information without being reliant on other computers i.e sharing files between two computers.
