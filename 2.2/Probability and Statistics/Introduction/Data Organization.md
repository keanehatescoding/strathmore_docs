## Frequency distribution
A frequency distribution is a table that lists categories of items along with their corresponding frequencies.
### Guidelines for constructing a frequency distribution table
1. The classes must be mutually exclusive. That is, each score must belong to exactly one class.
2. The classes must be exhaustive meaning there should be enough classes to accommodate all data
3. All classes should have the same width
4. The number of classes should be between 5 and 20
### Procedure for constructing a frequency distribution table
1. Sort the data
2. Find the Range($R$) of the data which is given by $R=\text{Largest Value}-\text{Smallest Value}$
3. Find $K$ which is given by $K=1+\frac{\log N}{\log 2}$ or $K=1+3.322\times\log N$  where $N$ is the number of items in the set.
4. Finally find $W$ which is given by $W=\frac{R}{K}$ 
5. Write down your lowest value
6. Add the class width from Step 4 to Step 5 to get the next lower class limit.
7. Repeat Step 6 for the other minimum data values until you have created the number of classes you chose in Step 1.
8. Write down the upper class limits which is given by the upper class limits - 1
9. Add a second column for the number of items in each class, and label the columns with appropriate headings:
### Terminology
__Grouped data:__ Data organized into a frequency
distribution table
__Class frequency__: The number of observations in each
class.
__Class relative frequency__: The percent of observations in each class.
__Class cumulative frequency__: The total observations up to certain class
__Class Midpoint__: A point that divides a class into two
equal parts, i.e. the average of the upper and lower class limits values.
__Class interval__: The difference between two consecutive lower class limits.
## Histogram
__Histogram__: Displays the data by using continuous vertical bars of various heights to represent the frequencies of the classes.

## Frequency Polygon
__Frequency polygon__: Consists of line segments connecting the points formed by the class midpoint and the class frequency.
## Cumulative frequency polygon
__Cumulative frequency polygon__: The ogive is a graph that represents the cumulative frequencies for the classes in a frequency distribution
