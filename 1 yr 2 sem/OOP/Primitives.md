These are data types that lack methods and are the fundamental data types in the Java Language i.e a int is just a 32 bit signed numeric value that can only be performed numeric operations and be returned as the return type.
There are types of primitive types
## 1. Integer Primitive Types
1. byte  8 bits -128 to 127
2. short 16 bits -32768 to 32767
3. int signed 32 bit number $-2^{32}-1$ to  $-2^{32}$
3. long 64 bits $-2^{64}-1$ to $2^{64}$
## 2. Floating-point Primitive Types
1. float 32 bits
2. double 64 bits

## 3. Other Primitive Types
1. Char 16 bits
2. Boolean 32 bits

They can never be null
