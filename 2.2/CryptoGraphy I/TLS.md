Similar to the 3-way <abbr title="Transmission Control Protocol">TCP</abbr> handshake we also have the TLS 3-way handshake.
The first 2 steps are:
1. Client Hello
2. Server Hello
3. Authentication
4. The premaster secret
5. Private key used
6. Session keys created
7. Client is ready
8. Server is ready
9. Secure symmetric encryption achieved
