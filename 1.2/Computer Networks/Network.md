# Networks

What is a network? __A network is a collection of computers connected via a transmission media and protocols.__

Networks can be characterized according to:
3. Management
4. Size
5. Access

## Classification according to Management
### 1. Client-server Networks
This is a type of network where computers request resources i.e printing services, email services etc to a computer from a  more powerful computer called a server i.e a web server, proxy etc.

In the past these clients were much less powerful and clients were physical terminals stations that used to just send instructions and data that the powerful servers would process data and transmit the processed data back to this terminal clients.

#### Advantages of Client-Server Networks
1. Better security compared to p2p Networks

#### Disadvantages of Client-Server Networks
1. It is more complex to set up.
2. Initial cost of setting up is very high especially for the server.

### 2. Peer to peer networks
This is a type of network were computers are mostly connected to each other for just sharing information without being reliant on other computers i.e blockchain

#### Advantages of p2p networks
1. Easy to create
2. Lest cost to implement
3. Less complex to manage

#### Disadvantages of p2p networks
1. Has worse security compared to client-server networks

## Classification according to Access
### 1. Intranet
This is a network which only connects members that belong to that organization i.e staff.

### 2. Extranet
This is a network which allows members from other networks to connect with members in that organization i.e staff and customers, suppliers or contractors.

## Classification according to Size
### 1. LAN
A __Local Area Network__ is a type of network that provides access to users and end devices in a small geographical area i.e a home or a small office/home office(SOHO).

### 3. WAN
A __Wide Area Network__ is a type of network that provides access to very many devices that span a large geographical area.
