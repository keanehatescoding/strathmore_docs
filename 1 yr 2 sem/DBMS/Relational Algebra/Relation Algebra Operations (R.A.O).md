These work on one or more relations to define another relation without changing the original relations.
These are the basic relational algebra operations that we are going to be using in this class:
1. Selection/Restriction $\sigma _F{(R)}$
2. Projection $\pi _{\text{col1 }, \text{col2}, ... ,\text{col n}} (R)$
3. [[1 yr 2 sem/DBMS/Relational Algebra/Cartesian Product|Cartesian Product]] $R\times S$
4. [[Union|Union]] $R \cup S$
5. [[Set Difference|Set Difference]] $R-S$
6. [[Intersection|Intersection]] $R \cap S$
