# Networks

What is a network? A network is a collection of computers connected via a transmission media and protocols.
## Type of Networks

1. __Client-server__ networks - where computer(s) request resources i.e printing services, email services etc to a computer from a usually more powerful computer called a server i.e a web server, proxy etc.
In the past these clients were much less powerful and clients were physical terminals stations that used to just send instructions and data that the powerful servers would process data and transmit the processed data back to this terminal clients.
2. __Peer to peer networks__ - a network were computers are mostly connected to each other for just sharing information without being reliant on other computers i.e blockchain

Next we will be talking about the various equipment used when networking in the [Networking Equipment] .

## Advantages of P2P networks
1. Easy to create
2. Lest cost to implement
3. Less complex to manage
