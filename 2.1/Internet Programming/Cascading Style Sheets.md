<abbr title="Cascading Style Sheets">CSS</abbr> is used to format the layout of a webpage(s). The term term __Cascading__ means that any attribute applying to any parent element will also apply to any child element.
The 3 types of CSS.
1. __Inline CSS__- you define the css using the style attribute inside the element.
2. __Internal CSS__- you define the css using the style attribute in the head element of the html document.
3. __External CSS__ - you define the css using a css stylesheet which is referenced inside the html document using the link attribute.
