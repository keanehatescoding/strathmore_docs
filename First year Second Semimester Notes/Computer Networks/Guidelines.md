## Cisco Packet tracer
This is a tool that you would in order to setup a virtual network to emulate setting up an actual network. It can be downloaded from this [website]([https://www.netacad.com/resources/lab-downloads](https://www.netacad.com/resources/lab-downloads?courseLang=en-US)
For arch based system. I use Arch btw you have to install the debian package then install it via pacman. This is well documented in the AUR just [click here](https://aur.archlinux.org/packages/packettracer)
## Personal recommendations
I am putting here what I feel is very likely to be tested
1. OSI and TCP/IP model - can you explain what happens in every layer
2. ARP and RARP protocols - can you explain how a packet traverses through a network using these protocols.
3. Knowing networking theoretically vs practically. Can you subnet a network theoretically and using packet tracer.
4. Find IT questions and answer them. I am linking a few sites that our exams were set based on.
5. Apart from classwork try and do networking certifications, you may learn one or two things which you may not learn in class.
