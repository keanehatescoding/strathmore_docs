__Data communication__ is the electronic transmission of data or information between two devices via some form of transmission media.
The five components of data communication are:
1. Message
2. Sender/Transmitter - a collection of electrical components that convert electrical signals to signal suitable for transmission over a given medium
3. Recipient - ac collection of electronic components that accept and convert a transmitted message to a form understandable by humans.
4. Media/Channel
5. Protocol
6. Noise
__Protocol__ is a set of rules that govern communication.
__Transceivers__ is a device that can both send and receive back signals i.e telephones, faxes, modems etc.
__Multimedia data__ incorporates __audio, video__ and __images__.

## Key elements of a protocol
1. Syntax - structure or format of the data
			- indicate how to read the bits
2. Semantics - interprets the meaning of the bits
			- which fields define what action
3. Timing - when data should be sent and what data we have to send
			- speed of sending/receiving data


__Standards__ on the other hand provide guidelines for manufacturers/vendors/government agencies/service providers
or a set of agreed upon rules.

### Types of Standards
1. De facto - by convention/ by fact
2. De jure - by law/by goverment

### Standard Organization
1. ISO
2. IEEE
3. ANSI
