Dhcp Server uses UDP port 67.
Dhcp Client uses UDP port 68.

Dhcp Discover - broadcast message asking if their is a dhcp server in the network.
Dhcp Offer - mostly a unicast but it can be broadcast message offering a ip address to the client.
Dhcp Request - a broadcast message that tells the dhcp server they want to ask to use the offered address.
Dhcp ack - tells the client that they have acknowledged that they are going to use that dhcp offer given.
DORA - discover offer request acknowledge
