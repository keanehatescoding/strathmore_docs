
## Superkey

A attribute or a group of attributes which uniquely identify an attribute in a relation.
or
It consists of a candidate key's attributes + potentially some extra attributes.

## Candidate Key

This is a set of possible attributes(candidates) that could possibly be the primary key of a relation.
A candidate key __must__ be unique over time i.e it is very very unlikely to change over time. If it seems unique now but it change over time they it is not an ideal candidate key.

## Alternate key

__NB:__ You can never have multiple primary keys in a relation
