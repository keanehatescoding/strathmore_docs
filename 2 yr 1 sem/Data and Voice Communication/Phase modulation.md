This is a type of signal modulation whereby the phase of the carrier signal is varied to represent the data added to the signal i.e if the function of the signal is given by:
$$s(t)=A_{c}\cos(\omega_{c}t+\phi(t))$$
then $\phi_(t)=F(m(t))$ 
The modulated signal is therefore given by:
$$S_{PM}=A\cos(2\pi f t + k_{p}m(t))$$
